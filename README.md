# Apex School Management System

A modern, responsive, and intuitive web application designed for school administration and academic management. Built with **React**, **Vite**, **Tailwind CSS**, and **Lucide React**.

---

## 🌟 Key Features

- **📊 Comprehensive Dashboard**: Real-time overview of total students, active teachers, fee collections, attendance rates, and quick action shortcuts.
- **🎓 Student Management**: Complete student records, search and filter capabilities, admission status, and student profiles.
- **👨‍🏫 Teacher Management**: Faculty directory, department assignments, and contact details.
- **📅 Attendance Tracking**: Daily student attendance logging, status indicators (Present, Absent, Late), and quick mark actions.
- **💳 Fee Management**: Fee collection tracking, overdue alerts, invoice status (Paid, Pending, Overdue), and payment summaries.
- **📝 Exam & Gradebook**: Examination scheduling, subject-wise scoring, and automated grade calculation (A+, A, B, C, F).
- **⚙️ Settings & Configuration**: Customizable school profile, academic session management, and multi-currency support ($ / PKR).
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile screens with slide-out navigation.

## 🛠️ Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine (version 18+ recommended).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/farmanadil500-debug/school-system-managment-.git
   cd school-system-managment-
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

---

## 📦 Build for Production

To generate an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
